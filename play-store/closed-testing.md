# Closed testing (personal account: 12 testers, 14 days)

A personal developer account must run a closed test with **at least 12 testers who stay opted in for 14 days in a row** before it can apply for production. The 14 days only count while 12 or more testers are opted in, so invite 15 to 20 people.

## 1. Testers list

Play Console → **Test and release → Testing → Closed testing** → Create track (or use "Alpha") → **Testers** tab → Create email list:

- List name: `DHI testers`
- Paste the Gmail IDs, comma separated. Each tester needs the Gmail they use in the Play Store on their phone.

## 2. Release

Same track → **Create release** → upload `app-release.aab` → Release name `1.0.5 (18)`.

Release notes:

```
<en-US>
First Play Store test of the DHĪ Ayurveda Classroom app: live classes, notes, tests, doubts and your profile in one place.
</en-US>
```

Countries: **India**. Then Save → Review release → Start rollout to Closed testing.

## 3. Message for testers (WhatsApp)

After rollout, copy the **"Join on Android"** link from the Testers tab and send:

```
Namaste 🙏
DHĪ Ayurveda Classroom ka app Play Store pe aa raha hai, aur usse pehle Google ko 14 din ka test chahiye. Aapki thodi madad chahiye:

1. Ye link phone me kholiye (wahi Gmail jo Play Store me hai): <JOIN LINK>
2. "Become a tester" dabaiye
3. Wahin se "Download it on Google Play" se app install kariye
4. 14 din tak app phone me rakhiye aur beech beech me khol lijiye. Uninstall mat kariye 🙏

Koi dikkat aaye to isi number pe bata dijiye. Dhanyavaad!
```

## 4. After 14 days

Dashboard → **Apply for production**. Google asks a few questions about the test (how many testers, what feedback, what changed). Answer honestly in short sentences.
